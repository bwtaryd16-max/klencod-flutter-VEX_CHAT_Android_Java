VEX CHAT - مشروع Android بلغة Java

- الواجهة مبنية برمجياً داخل MainActivity.java دون ملفات XML للتصميم.
- المجلدات: الكل، غير المقروءة، الشخصية، المجموعات، القنوات، المفضلة، العمل.
- أزرار التنقل: المحادثات، جهات الاتصال، الإعدادات، الملف الشخصي.
- هذه نسخة واجهة تجريبية محلية: لا يوجد خادم أو إرسال رسائل حقيقي بين الأجهزة بعد.
- افتح المجلد في Android Studio أو ارفع محتوياته إلى مستودع GitHub مع إعداد GitHub Actions لبناء APK.
